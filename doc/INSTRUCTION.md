# Інструкція для ШІ: додавання блоку за шаблоном

## Проєкт
- React + Vite, стилі тільки SCSS.
- Кожен блок = окремий компонент у `src/components/<BlockName>/`:
  - `<BlockName>.jsx`
  - `<BlockName>.scss`
- Зараз проєкт одностор­інковий. Роутинг може з'явитися пізніше, сам його не додавай.

## Твоє завдання
Я надаю шаблон блоку (JSX + SCSS) і дані. Ти переробляєш шаблон під мій
проєкт і ДОДАЄШ його як новий блок. Більше нічого.

## Що ЗАБОРОНЕНО
1. Змінювати, виправляти або рефакторити наявний код.
2. Додавати нові бібліотеки, пакети, шрифти, іконки (не запускай `npm install`).
3. Змінювати розмітку шаблону: теги, порядок, кількість елементів.
4. Змінювати структуру папок і чіпати файли, які я не назвав.
5. Додавати свої «покращення» й анімації, яких нема в шаблоні.
6. Самостійно додавати `@media` (див. розділ «Адаптивність»).

## Що МОЖНА змінювати
1. Назви класів: під назву блоку (правила BEM нижче).
2. Тексти, посилання, картинки: тільки ті, що я дав.
3. Кольори та шрифти беруться зі стилів проєкту
   (змінні в `src/styles/`, якщо вони є).
   Якщо в проєкті теми ще нема, залиш кольори з шаблону.

## Правила BEM
- Блок: `hero`
- Елемент: `hero__title` (завжди блок + `__` + елемент)
- Модифікатор: `hero__btn--primary`
- Вкладені елементи НЕ ланцюжимо:
  - правильно: `hero__title`
  - неправильно: `hero__content__title`
- У SCSS використовуй вкладеність через `&`:

```scss
.hero {
  &__title { }
  &__btn {
    &--primary { }
  }
}
```

## Адаптивність (mobile-first)
- Базові стилі пиши під мобільний екран (від 320px) без `@media`.
- Ніколи не додавай `@media` на власний розсуд:
  ні для планшета, ні для десктопа.
- Якщо `@media` вже є в шаблоні, не видаляй і не змінюй їх, залиш як є.
- `@media` додаю я сам, або прошу тебе окремим запитом
  (наприклад: «додай @media для 768px у блок Services»).
- Коли я прошу додати `@media`, використовуй mobile-first:
  `min-width`, а не `max-width`.

## Підключення
- У JSX: `import './<BlockName>.scss';`
- Додай `<BlockName />` у `App.jsx` в кінець списку блоків
  (або туди, де я скажу). Наявні рядки не чіпай.

## Формат відповіді
1. Список файлів, які ти створив або змінив.
2. Код кожного файлу повністю.
3. Якщо чогось не вистачає, запитай мене. Не вигадуй.
